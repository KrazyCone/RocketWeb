Opening and saving designs

        
      


      

        

          
Open a design from your computer

          
    
            
  1. 
              Upload button (easiest): CheerpJ draws an upload arrow in the
              title bar of the OpenRocket window. Use it to pick a .ork file, then
              choose File → Open inside OpenRocket.
            
    2. 
            
  2. 
              Toolbar: press Open .ork… at the top of this page. The
              file is staged in the virtual filesystem at /str/<filename>.
              In OpenRocket choose File → Open… and type that path into the file name
              field.
            
    3. 
            
  3. 
              Bundled examples: OpenRocket ships example rockets inside the JAR —
              use File → Open Example in the app menu for an instant design to play with.
            
    4. 
          

        


        

          
Save a design or simulation CSV to your device

          
    
            
  1. 
              In OpenRocket use File → Save As… (or Export for CSV) and save
              into /files/downloads/. CheerpJ 4.3 sends files saved there straight to
              your browser's download folder.
            
    2. 
            
  2. 
              Saved somewhere else under /files/? Press
              Save to device… on this page and enter the file name — the page reads it
              out of the virtual filesystem and downloads it.
            
    3. 
            
  3. 
              Files under /files/ persist in this browser between visits, so an
              interrupted session is not lost.
            
    4. 
          

        


        

          
What is different from the desktop app

          
    
            
  • 
              The 3D flight visualisation uses OpenGL (JOGL) and does not run in WebAssembly;
              2D views, component editing and the simulation engine work normally.
            
    • 
            
  • Printing, native file dialogs outside the virtual filesystem and OS integration are unavailable.
    • 
            
  • Large simulations run noticeably slower than on a desktop JVM.
    • 
            
  • Your designs never leave your device: no upload, no account, no server.
